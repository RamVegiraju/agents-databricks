# Northstar returns policy

Demo policy, effective 2026-10-01. Products may be returned within 30 calendar
days of delivery when unused and accompanied by proof of purchase. Rain Shell
and Trail Runner follow the same standard window. Final-sale items cannot be
returned unless defective. Refunds use the original payment method. Escalate
defective goods and exceptions to a human support specialist; this assistant
does not authorize refunds.
